# 学生作业检查系统 - 多班级版

**雷州市职业高级中学 · 林勇良 开发**

一个基于 Python 和 Tkinter 的桌面应用程序，用于自动检查学生作业提交情况、检测作业间的相似度（抄袭嫌疑），并提供考勤统计与作业迁移功能。系统支持多班级管理，适合机房教学环境。

---

## 功能特性

- **多班级管理**：可创建/删除班级，每个班级独立配置学生名单、作业目录、检查模式等。
- **三种检查模式**：
  - **文件夹模式**：以学生姓名为文件夹，检查文件夹内文件。
  - **文件模式**：在根目录中递归查找以学生姓名命名的文件。
  - **混合模式**：优先匹配学生文件夹，找不到时再查找文件，适合混合提交场景。
- **智能姓名匹配**：支持“学号+姓名”等多种命名方式，自动识别学生文件夹或文件。
- **作业提交状态统计**：已提交 / 未提交 / 疑似抄袭分类，并按学生、文件名、时间、相似度等进行多级排序。
- **相似度（抄袭）检测**：
  - 结合 MD5 快速比对与多维度文本相似度计算（基本序列匹配、过滤模板代码后的匹配、行级匹配、代码结构匹配）。
  - 可自定义相似度阈值，超过阈值的学生文件将被标记为“疑似抄袭”。
- **考勤功能**：指定考勤文件夹，自动合并15分钟内的文件，模糊匹配学生姓名，生成已到/缺勤名单（支持一行多个显示，自动换行）。
- **自动刷新**：可设置间隔时间，自动重新检查作业。
- **作业迁移**：将当前班级作业按时间戳结构复制到指定目录，便于归档。
- **日志系统**：详细记录程序运行过程、错误及检查结果，方便排查问题。
- **右键快捷操作**：查看文件详情、打开文件位置、按列排序等。
- **配置导入/导出**：班级配置可导出为 JSON 文件，便于备份或迁移。

## 安装与运行

### 方式一：直接运行源码

1. 克隆或下载本仓库到本地。
2. 确保已安装 Python 3.7+ 和依赖库。
3. 在终端中执行：

```bash
python main.py
```

### 方式二：使用打包后的可执行文件

生成的可执行文件位于 `build` 目录下，可直接双击运行，无需安装 Python 环境。

## 使用说明

### 1. 班级管理

- 左侧面板可切换、新建、删除班级。
- 每个班级独立保存其学生名单、作业目录、检查模式等设置。
- 支持**导出/导入**班级配置（JSON 文件）。

### 2. 学生名单

- 在“学生名单”文本框内，每行一个学生姓名（支持学号+姓名格式，如 `01张三`）。
- 可通过“保存名单”按钮保存，或通过“导入名单”从 `.txt` 文件批量导入。

### 3. 作业检查

**步骤：**

1. 在“作业根目录”中选择存放学生作业的文件夹。
2. 根据需要选择检查模式（混合模式推荐）。
3. 设置支持的文件扩展名（可添加/删除，如 `.py`, `.txt`, `.java` 等）。
4. 点击“立即检查”：
   - 系统将扫描根目录，匹配学生姓名，统计提交情况。
   - 自动进行相似度检测，并更新“检查结果”表格。
   - 结果包含学生、文件名、状态、相似度、详细信息、最后更新时间等列。

**排序提示：** 点击列标题可按不同字段排序（状态、相似度、学生、文件名、时间），再次点击切换升降序。

### 4. 抄袭检测设置

- 在“相似度阈值(%)”中调整阈值（默认 85%），超过该值的相似度将被标为“疑似抄袭”。
- 双击某条记录可查看详细作业内容及具体相似文件列表。

### 5. 考勤功能

1. 选择包含考勤 `.txt` 文件的“考勤文件夹”。
2. 点击“考勤统计”：
   - 系统将自动合并最近 15 分钟内的文件。
   - 模糊匹配系统学生名单，生成已到和缺勤名单。
   - 结果展示包含出勤率、使用的考勤文件等信息。

### 6. 作业迁移

1. 点击“作业迁移”，选择目标目录。
2. 系统会按 `目标目录/班级名/年月日时/学生名` 的结构复制作业文件，方便归档。

### 7. 自动刷新

- 勾选“启用”自动刷新，设置间隔秒数（5–300秒）。
- 程序将在后台定时重新检查作业，适用于实时监控提交情况。

## 配置文件

- 所有班级配置保存在程序同级目录下的 `class_configs.json` 中，包含学生名单、根目录、扩展名、检查模式等。
- 可通过对配置文件的导出和导入功能，在不同设备间迁移班级设置。
- 日志文件保存在 `log.txt`，记录系统启动、检查过程、错误等信息，便于调试。

## 相似度检测算法说明

为确保检测准确性，系统采用多维加权相似度：

1. **MD5 快速比对**：完全相同文件直接标记 100% 相似度。
2. **基本序列匹配**：`difflib.SequenceMatcher` 比较原始文件。
3. **过滤模板后匹配**：移除常见导入语句、注释、类/函数声明等模板代码后再比较。
4. **行级相似度**：统计过滤模板行后的相同行占比。
5. **代码结构相似度**：针对代码文件，提取函数/方法名称进行结构比对。
6. **文件大小差异惩罚**：大小差异过大时适度降低相似度，减少误判。

最终相似度 = 预处理相似度 × 0.4 + 基本相似度 × 0.3 + 行相似度 × 0.2 + 结构相似度 × 0.1

## 注意事项

- 学生姓名匹配依赖于模糊搜索，请确保学生名单的姓名与作业文件夹/文件名的姓名部分一致。
- 若使用“文件夹模式”，请保证学生文件夹直接位于根目录下或最新子文件夹内。
- 大量文件检测时，相似度计算可能耗时，系统会自动调整线程数以优化性能。
- 考勤统计依赖 txt 文件，且系统采用 15 分钟内的时间窗口合并文件，适用于上课签到文件多次上传的场景。
- 关闭程序时，系统会自动保存当前班级配置，无需手动保存。
